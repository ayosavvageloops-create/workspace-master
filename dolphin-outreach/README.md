# Dolphin Outreach × IG Sender Pro

Запускает профили **Dolphin{anty}** потоками (например, по 3 окна одновременно), в каждом профиле
сам загружает в **IG Sender Pro** (режим «2026») пачку из 25 артистов с их личными опенерами,
жмёт «Запустить», следит за прогрессом и записывает результат в общую базу. Как только профиль
закончил, он закрывается и стартует следующий.

```
Панель (localhost:4747)
  ├─ база артистов + опенеры (CSV из Artist Finder / шаблоны)
  ├─ выбор профилей Dolphin и порядок запуска
  └─ диспетчер: N окон одновременно
        └─ профиль Dolphin ─► вкладка Instagram ─► IG Sender Pro: pairs = 25 × (артист → опенер) ─► startProcess()
                                                  ◄─ статусы: отправлено / пропущен / ошибка / ограничение IG
```

Код расширения **менять не нужно**: лаунчер заходит в него через DevTools (тот же канал, что
использует Dolphin API для автоматизации) и пишет в его `chrome.storage.local` те же ключи,
что пишет вкладка «2026» в настройках.

## Что умеет

- **Потоки**: сколько окон одновременно и сколько артистов на профиль — задаёшь перед запуском.
- **Без дублей**: один артист никогда не попадёт в два профиля. Плюс расширение в каждом профиле
  само пропускает тех, кому этот аккаунт уже писал.
- **Лимит на профиль в сутки** (по умолчанию 25): если профиль сегодня уже отправил 25, он пропускается.
- **Ограничение Instagram** (action blocked / challenge): профиль сразу останавливается, помечается
  до конца дня, его неотправленные артисты возвращаются в общую очередь и уйдут с других профилей.
- **Опенеры**: свой текст на каждого артиста (из CSV или руками в таблице), либо собирается из
  шаблонов со спинтаксом `{Yo|Hey}` и переменными `{{first_name:bro}}`, `{{track}}`, любая колонка CSV.
- **Остановка в любой момент**: расширение доделывает текущего артиста, профили закрываются,
  неотправленные возвращаются в очередь.
- Если программу закрыли посреди рассылки — при следующем старте «в работе» вернутся в очередь.
- Экспорт базы в CSV (кто, каким профилем, когда, с каким текстом).

## Установка (один раз)

1. Поставь **Node.js 22 или новее**: https://nodejs.org (кнопка LTS).
2. В Dolphin{anty} добавь **IG Sender Pro** в расширения (Расширения → Добавить → загрузить zip)
   и убедись, что оно включено в нужных профилях.
3. В каждом профиле один раз залогинься в Instagram и проверь настройки расширения
   (паузы на вкладке «Основная», способы отправки на вкладке «2026») — либо задай их централизованно
   в панели (Настройки → Расширение).
4. API-токен Dolphin: Dolphin → Настройки (профиль/аккаунт) → API → создать токен.

## Запуск

- Windows: двойной клик по `start.bat`
- macOS: двойной клик по `start.command` (если ругается — `chmod +x start.command`)
- или в терминале: `npm start`

Откроется панель **http://localhost:4747**. Dolphin{anty} должен быть запущен на этом же компьютере.

1. **Настройки** → вставь API-токен → «Сохранить».
2. **Профили** → «Загрузить из Dolphin» → кликами выбери профили (цифра = порядок запуска).
   Можно отфильтровать по тегу и «Выбрать отфильтрованные».
3. **Артисты** → вставь/загрузи CSV (экспорт Artist Finder подходит как есть) → «Импортировать».
   Проверь опенеры, кликни по тексту, чтобы поправить.
4. **Опенеры** → шаблоны для тех, у кого нет своего текста (кнопка «Превью» показывает 5 примеров).
5. **Запуск** → окон одновременно (3), артистов на профиль (25) → «Показать план» → «▶ Запустить».

## Форматы импорта

| Колонка в CSV | Что значит |
|---|---|
| `instagram`, `username`, `ig`, `link`, `ник` | ник или ссылка на профиль (обязательно) |
| `artist`, `name`, `имя` | имя → `{{name}}`, `{{first_name}}` |
| `message`, `opener`, `dm`, `опенер` | готовый опенер для этого артиста |
| любая другая (`track`, `genre`, …) | переменная `{{track}}`, `{{genre}}` в шаблонах |

Без заголовка: `ник, имя, опенер` в строке, или просто список ников/ссылок.
Разделитель — запятая, точка с запятой или табуляция; кавычки и переносы строк внутри ячейки понимаются.

## Настройки (`config.json`, правится из панели)

| Параметр | По умолчанию | |
|---|---|---|
| `run.concurrency` | 3 | окон одновременно |
| `run.artistsPerProfile` | 25 | артистов на профиль за сессию |
| `run.dailyLimitPerProfile` | 25 | максимум отправок с профиля в сутки |
| `run.startStaggerSec` | 15 | пауза между стартами окон первой волны |
| `run.profileTimeoutMin` | 240 | дольше этого профиль принудительно останавливается |
| `run.closeWhenDone` | true | закрывать профиль после рассылки |
| `extension.mode` | `igsender` | `manual` — только открыть профили, список с опенерами показывается в панели, отмечаешь сам |
| `extension.name` / `id` | IG Sender Pro | как найти расширение (по названию из manifest или по ID) |
| `extension.delays` | null | `{min, max}` сек между артистами для всех профилей; null — как в расширении |
| `extension.methods` | null | `{dm, story, post}` — способы отправки; null — как в расширении |

Токен можно не хранить в файле, а передать переменной окружения `DOLPHIN_TOKEN`.

## Что внутри

- `src/dolphin.js` — локальный API Dolphin (`/v1.0/browser_profiles/:id/start?automation=1`, `/stop`,
  `/v1.0/auth/login-with-token`) и облачный список профилей.
- `src/cdp.js` — DevTools-клиент без зависимостей.
- `src/igsender.js` — адаптер IG Sender Pro: поиск service worker расширения, загрузка `pairs`,
  `startProcess()` / `stopBot()`, чтение статусов.
- `src/runner.js` — диспетчер потоков, лимиты, ограничения, возврат в очередь.
- `src/db.js` — база в `data/*.json` (артисты, шаблоны, профили, история прогонов).
- `src/server.js`, `public/` — панель.

Данные (`data/*.json`) и `config.json` с токеном в git не попадают.

## Тесты

`npm test` — юнит-тесты и сквозной тест: настоящий Chromium, фейковый API Dolphin и макет
IG Sender Pro с тем же форматом хранилища (3 профиля, 2 окна одновременно, пропуски, ошибки,
ограничение Instagram).
