Импорт

CSV / TSV / вставка из Google Sheets. Понимает экспорт Artist Finder (artist, instagram, track, message…): ник из instagram, опенер из message. Без заголовков: ник, имя, опенер по строке или просто список ников / ссылок. Если опенера нет — он соберётся из шаблонов на вкладке «Опенеры». Дубли пропускаются.

Шаблоны опенеров

Каждому артисту без своего опенера случайно выбирается шаблон (с учётом веса) и собирается уникальный текст. {Yo|Hey|What's good} — случайный вариант, {{first_name}}, {{name}}, {{username}}, {{track}} и любая колонка из CSV. {{first_name:bro}} — «bro», если имени нет. Новая строка в тексте = перенос строки в сообщении.
