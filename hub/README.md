# Beat Hub — пульт на MacBook

Локальная страница `http://127.0.0.1:8787`, с которой ты:
- **Пульт**: запускаешь скрипты (рассылка Dolphin, рассылка лупов, фоллоу-апы) кнопкой и видишь лог;
- **День**: отмечаешь ежедневные целевые действия и видишь прогресс месяца к $10k;
- **Проверка текста**: проверяешь шаблон первого сообщения на стоп-слова и спам-паттерны;
- **План $10k**: калькулятор «цены и конверсии → дневные нормы».

Нужен только Python 3 (на Mac уже есть). Ничего ставить не надо.

## Запуск
```bash
cd workspace-master/hub
python3 hub.py
```
Или двойной клик по `start-hub.command` в Finder. Если macOS заблокирует запуск: правый клик → «Открыть».

## Подключить твои скрипты Dolphin
Открой `tasks.json` и для каждой кнопки впиши:
- `cmd`: ровно то, что ты сейчас набираешь в терминале для запуска рассылки;
- `cwd`: папку проекта с автоматизацией.

`"confirm": true` спрашивает подтверждение перед запуском. Логи лежат в `data/logs/`, счётчики дней в `data/days.json` (в git не попадают).

## Настройка
- `daily.json`: ежедневные нормы (пересчитай под себя через вкладку «План $10k»).
- `stopwords.json`: категории стоп-слов. Пополняй по итогам тестов (см. `../plan/10k-plan.md`, раздел 3).
- Другой порт: `HUB_PORT=9000 python3 hub.py`.
