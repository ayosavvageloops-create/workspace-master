# Type Beat Leads — Chrome-расширение (этап 1)

Лидогенерация артистов через чужие type beat-каналы: не нужно строить свой канал, достаточно найти
продюсеров в своём стиле и забрать тех, кто у них уже хочет купить бит.

```
YouTube: «Rylo Rodriguez type beat»
   └─ самые просматриваемые type beat-каналы → «О канале»: подписчики + Instagram
      └─ нет Instagram в «О канале» → открывается видео канала → Instagram из описания
Вы выбираете продюсеров (галочки, Instagram можно поправить)
Instagram каждого выбранного продюсера
   ├─ открывается каждый пост → «ещё комментарии» → «Check DM», «How much?», «Where can I buy this?»
   ├─ вкладка Tagged → открывается каждый пост → его автор (обычно артист с треком на бите)
   └─ артисты, упомянутые в подписях к постам продюсера (плейсменты)
Каждый кандидат → переход на профиль → проверка «артист или нет» → таблица лидов + CSV
```

**Без API.** Всё делается действиями во вкладках, как руками: открыть страницу, прокрутить,
нажать «загрузить ещё комментарии», прочитать то, что на экране. Никаких запросов к внутренним
API Instagram/YouTube.

## Установка

1. Скачайте папку `type-beat-leads` (или весь репозиторий).
2. Откройте `chrome://extensions`, включите **Режим разработчика**.
3. **Загрузить распакованное** → выберите папку `type-beat-leads`.
4. Войдите в Instagram в этом же браузере (расширение работает от вашей сессии).
5. Нажмите на иконку расширения — откроется боковая панель.

Нужен Chrome 116+ (или другой Chromium-браузер с поддержкой боковой панели).

## Как пользоваться

1. Впишите запрос (`Rylo Rodriguez type beat`, `Huncho type beat` …), сколько раз прокрутить
   выдачу и сколько каналов открыть.
   Если продюсеры уже известны — впишите их Instagram в поле «…или сразу Instagram продюсеров»,
   тогда шаг YouTube пропускается.
2. **Запустить.** Вкладка YouTube откроет поиск, затем «О канале» каждого канала (а если там нет
   Instagram — одно-два видео канала).
3. **Выбор продюсеров.** В панели появится список каналов: подписчики, найденный Instagram и откуда
   он взят. Самые крупные отмечены заранее — поправьте галочки или впишите Instagram вручную и
   нажмите **«Сканировать Instagram»**. (Галочка «Не спрашивать» — сразу брать отмеченных.)
4. Вкладка Instagram пройдёт по постам, Tagged и профилям кандидатов. Прогресс и журнал — в панели.
5. Лиды появляются по ходу работы. «Открыть таблицу» — полная таблица с фильтрами, статусами
   («Новый → Написал → Ответил → Созвон…») и экспортом в CSV/JSON.

### Приоритеты лидов

| Приоритет | Что значит |
|---|---|
| 🔥 **Горячий** | Артист, который в комментарии прямо спрашивал про покупку/цену/DM |
| **Тёплый** | Артист из Tagged, плейсментов или с более слабым сигналом в комментарии |
| **Не артист** | Профиль проверен, но похож на продюсера/студию/прочее |
| **Не проверен** | Кандидат найден, но профиль ещё не открыт (лимит проверок) — запустите ещё раз |

Проверенные профили кэшируются (по умолчанию на 14 дней), поэтому повторный запуск не открывает
их заново и продолжает с непроверенных.

## Как определяется…

**Намерение купить** (`src/lib/classify.js → analyzeComment`): правила с весами — «check DM»,
«trying to buy», «how much», «price/cost», «where can I buy», «is this available», «send me the
beat», «need this beat», «hop on this» и т. д. Спам других продюсеров («check my page», «I make
beats») даёт минус. Порог по умолчанию — 4.

**Артист** (`classifyArtist`): категория профиля (Musician/Band, Artist → плюс; Music producer →
минус), слова в био (rapper, singer, out now, booking, features…), ссылки на Spotify/Apple Music/
SoundCloud/Audiomack/DistroKid/linktr.ee, минус за «producer / beats / drum kits / mixing &
mastering» и ник вида `prodby…`, `…beats`. Порог по умолчанию — 3. Причины решения видны в таблице.

**Какие посты продюсера открывать** (`scorePost`): берутся первые посты сетки профиля, рилсы и
посты с подписью про beat/prod/placement/out now/link in bio — в приоритете.

## Настройки и безопасность аккаунта

По умолчанию: пауза 2,5–6 с после каждой открытой страницы, до 8 постов с комментариями
(до ~100 комментариев на пост) и 24 постов Tagged на продюсера, до 60 профилей кандидатов за
запуск. Если Instagram показывает «Please wait a few minutes», расширение ждёт 3 минуты и
пробует ещё раз, а если не помогло — останавливается, сохранив всё найденное.
Не ставьте паузы меньше ~2 с и не запускайте много раз подряд.

Время одного запуска: каждая страница — это реальный переход (≈5–10 с), поэтому 3 продюсера
с настройками по умолчанию — примерно 20–40 минут. Вкладки можно не трогать, но не закрывайте их.

## Устройство

```
manifest.json            MV3, права: storage, tabs, scripting, sidePanel; хосты youtube.com, instagram.com
src/background.js        оркестратор: вкладки, этапы, выбор продюсеров, лимиты, кэш, сохранение лидов
src/lib/pagescripts.js   действия на страницах: ждать отрисовку, прокрутить, нажать «ещё», прочитать
src/lib/youtube.js       разбор выдачи, «О канале», описаний видео; поиск Instagram в тексте
src/lib/instagram.js     разбор шапки профиля, комментариев и автора поста
src/lib/classify.js      намерение в комментарии, «артист или нет», релевантность поста
src/lib/store.js         ключи chrome.storage, настройки по умолчанию, приоритеты лидов
src/ui/sidepanel.*       боковая панель: запуск, прогресс, журнал, топ лидов
src/ui/results.*         таблица лидов, фильтры, статусы, экспорт
```

Расширение только переходит по страницам во вкладках и читает отрисованную страницу
(`chrome.scripting.executeScript`). Данные хранятся только локально в `chrome.storage.local`.

Instagram и YouTube периодически меняют вёрстку. Если что-то перестало находиться, смотрите
журнал в панели — шаги там подписаны; всё, что зависит от вёрстки, собрано в `src/lib/pagescripts.js`.
