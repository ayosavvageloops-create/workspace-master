# FL Tutorial Recorder

Десктопное приложение на Electron. Записывает окно FL Studio вместе со звуком. Пока ты работаешь, ты горячими клавишами отмечаешь слои (kick, snare, луп…). Потом приложение само собирает вертикальный туториал в стиле «how i make beats»: интро, `step N: kick` с нужным куском записи и `full beat` с обложками. На выходе MP4 1080×1920 для TikTok.

## Запуск

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
cd fl-tutorial-recorder
npm install
npm start
```

Портативный `.exe` для Windows собирается командой `npm run dist`. Файл появится в `dist/`.

## Как пользоваться

1. Открой проект в FL Studio, потом запусти приложение. Оно само найдёт окно FL Studio. Если не нашло, нажми «Обновить» или выбери окно вручную.
2. Слева настрой названия меток. По умолчанию `Ctrl+Shift+1` = loop, `2` = kick, `3` = snare и т.д. `Ctrl+Shift+0` = full beat.
3. Нажми **«Начать запись»** и переключись в FL. Сверху появится плашка с таймером. В захват она не попадает.
4. Включи слой и нажми его клавишу. С этого момента запись становится шагом с этим названием. Потом следующий слой, и так далее. В конце запусти весь бит и нажми `Ctrl+Shift+0`.
   - `Ctrl+Shift+Z` убирает последнюю метку.
   - `Ctrl+Shift+R` останавливает запись.
5. После остановки запись перекодируется, чтобы по ней можно было быстро перематывать, и откроется **«Монтаж»**:
   - на ленте внизу видна вся запись с метками. Блоки шагов можно перетаскивать, чтобы выбрать нужный момент;
   - **«✂ Кадр»** выбирает, какая часть окна FL попадёт в видео (piano roll, плейлист, channel rack). Это задаётся отдельно для каждого шага или сразу для всех;
   - тексты интро, фото, обложки финала, BPM для смены обложек;
   - на превью тексты и фото можно таскать мышкой, колесо меняет размер.
6. **Текст и визуал.**
   - **Инспектор справа.** Кликни по любому тексту или картинке на превью. Для текста там содержимое, шрифт (системный или свой `.ttf`/`.otf`), размер, ширина букв, цвет, жирный и курсив, выравнивание, обводка, тень, точная позиция. Для картинки: размер, скругление, рамка, тень. Анимация появления общая: нет (резко, как в оригинале), pop, плавно, выезд снизу, наезд, печатная машинка. Кнопка «Применить этот стиль ко всем текстам» переносит оформление сразу на всё.
   - **Свои надписи и картинки.** Ник, «link in bio», логотип. Их можно показывать везде, только в интро, на всех шагах, на конкретном шаге или в финале, с нужной секунды.
   - **Визуал.** Шрифт и цвета по умолчанию, картинка на фон. Для полосы с записью: место и высота, отступы по бокам, скругление, рамка, яркость, контраст, насыщенность.
7. **«Экспорт MP4»**: видео записывается в реальном времени, потом кодируется в H.264 и сохраняется, куда скажешь.

Проекты лежат в `Видео/FL Tutorial Recorder/<дата>/`: там `recording.mp4`, `project.json` и картинки. Их можно открыть снова из списка «Последние проекты».

## Звук

- **Windows**: звук компьютера (всё, что играет FL) пишется автоматически.
- **macOS 13+**: звук системы берётся через ScreenCaptureKit. При первом запуске macOS попросит разрешить «Запись экрана и системного звука». На более старых macOS видео пишется без звука.

## macOS (Apple Silicon)

Горячие клавиши на Mac: **Control + Shift + цифра** (не Command: `Cmd+Shift+3/4/5` заняты скриншотами).

Установка из DMG:
1. Открой `FL-Tutorial-Recorder-arm64.dmg` и перетащи приложение в «Программы».
2. Приложение не заверено Apple, поэтому первый раз открой его так: правый клик по нему → «Открыть» → «Открыть». Если macOS пишет «приложение повреждено», выполни в Терминале:
   ```
   xattr -cr "/Applications/FL Tutorial Recorder.app"
   ```
3. Разреши запись экрана: «Системные настройки» → «Конфиденциальность и безопасность» → «Запись экрана и системного звука». Включи там FL Tutorial Recorder и перезапусти приложение.
