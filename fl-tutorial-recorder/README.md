# FL Tutorial Recorder

Десктопное приложение на Electron. Записывает окно FL Studio вместе со звуком. Пока ты работаешь, ты горячими клавишами отмечаешь слои (kick, snare, луп…). Потом приложение само собирает вертикальный туториал в стиле «how i make beats»: интро, `step N: kick` с нужным куском записи и `full beat` с обложками. На выходе MP4 1080×1920 для TikTok.

## Запуск

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
cd fl-tutorial-recorder
npm install
npm start
```

Портативный `.exe` для Windows собирается командой `npm run dist`. Файл появится в `dist/`.

## Как пользоваться

### Один раз: связь с FL Studio
Приложение управляет FL само: переключает паттерны, открывает piano roll или channel rack и запускает воспроизведение. Для этого нужна разовая настройка. Её же показывает кнопка **«Подключить FL Studio»**.

1. Нажми **«Установить скрипт»**. Приложение положит `device_FLTutorialRecorder.py` в `Documents/Image-Line/FL Studio/Settings/Hardware/FL Tutorial Recorder/`.
2. Запусти FL Studio **после** приложения. Если FL уже открыт, в MIDI settings нажми *Rescan devices*.
3. Во FL открой **Options → MIDI settings**:
   - **Input**: `FL Tutorial Recorder`, Controller type: `FL Tutorial Recorder`, Port: `10`, Enable;
   - **Output**: `FL Tutorial Recorder`, Port: `10`.
4. Плашка в приложении станет зелёной: **«подключено»**.

На Windows нужна бесплатная программа loopMIDI с двумя портами `FLTR to FL` (выбрать во FL как Input) и `FLTR from FL` (как Output).

### Запись
1. Открой проект во FL. Приложение само найдёт окно FL и покажет список паттернов.
2. Отметь, какие паттерны записать. Для каждого можно задать подпись в видео (kick, open hat…), что показать (piano roll нужного инструмента, channel rack или playlist) и сколько тактов играть. Последняя строка — **полный бит** в Song mode.
3. Нажми **«Записать автоматически»**. Приложение по очереди включает каждый паттерн, открывает нужное окно, ждёт заданное число тактов, потом играет весь бит, останавливается и сразу открывает готовый монтаж.

Если связи с FL нет, можно писать по-старому: включать паттерны самому и отмечать их **Ctrl+Shift+1…9** («Ручной режим»).

### Монтаж
- Клик по серому квадрату **«+ добавить фото»** открывает выбор картинки. Картинку можно и **перетащить** на превью, и **вставить** из буфера (Cmd+V / Ctrl+V).
- Клик по любому тексту или фото открывает справа его настройки: шрифт, цвет, обводка, тень, анимация появления, позиция.
- Лента внизу — вся запись: блоки шагов можно двигать. «✂ Кадр» выбирает, какая часть окна FL видна в ролике.
- **«Экспорт MP4»** сохраняет готовое видео 1080×1920.

Проекты лежат в `Видео/FL Tutorial Recorder/<дата>/`.

## Звук

- **Windows**: звук компьютера (всё, что играет FL) пишется автоматически.
- **macOS 13+**: звук системы берётся через ScreenCaptureKit. При первом запуске macOS попросит разрешить «Запись экрана и системного звука». На более старых macOS видео пишется без звука.

## macOS (Apple Silicon)

Горячие клавиши на Mac: **Control + Shift + цифра** (не Command: `Cmd+Shift+3/4/5` заняты скриншотами).

Установка из DMG:
1. Открой `FL-Tutorial-Recorder-arm64.dmg` и перетащи приложение в «Программы».
2. Приложение не заверено Apple, поэтому первый раз открой его так: правый клик по нему → «Открыть» → «Открыть». Если macOS пишет «приложение повреждено», выполни в Терминале:
   ```
   xattr -cr "/Applications/FL Tutorial Recorder.app"
   ```
3. Разреши запись экрана: «Системные настройки» → «Конфиденциальность и безопасность» → «Запись экрана и системного звука». Включи там FL Tutorial Recorder и перезапусти приложение.
