# Beat Tutorial Maker

Редактор вертикальных туториалов (1080×1920) в стиле TikTok «how i make beats for …»:

1. **Интро.** Белый фон, тёмно-синий узкий шрифт. Слова и фото появляются по одному.
2. **Шаги.** Заголовок `step N:`, название слоя и полоса с записью экрана из FL Studio. Есть подпись вроде `(full beat at the end)`.
3. **Финал.** `full beat` и обложки, которые меняются в такт (BPM × доли).

Весь проект — один файл `index.html`, без сборки и сервера.

## Как пользоваться

1. Открой `index.html` в **Google Chrome** (двойной клик по файлу).
2. Слева заполни тексты и загрузи файлы:
   - фото для интро;
   - записи экрана для шагов. Можно одну длинную запись на все шаги: у каждого шага укажи свой «старт в клипе»;
   - обложки для финала;
   - бит в разделе «Звук». Подойдёт и аудиофайл, и само видео.
3. Подгони кадр клипа: «зум», а также X и Y от 0 до 1. Значение X = 0 прижимает запись к левому краю, чтобы были видны клавиши piano roll.
4. На превью тексты и фото можно перетаскивать мышкой. Колесо меняет размер, Alt + колесо меняет ширину букв.
5. Нажми **«Экспорт видео»**. Видео пишется в реальном времени, поэтому не сворачивай вкладку. Chrome сохраняет MP4 (H.264), его можно сразу заливать в TikTok.

Тексты, тайминги и раскладка сохраняются в браузере. Файлы после перезагрузки страницы нужно загрузить заново.

Пробел запускает и останавливает воспроизведение.
