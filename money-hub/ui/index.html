Референс → Artist Finder находит похожих → делим по профилям Dolphin → каждому свой опенер → рассылка расширением.

Кого ищем

Тех, кому уже писали через Money Hub, Artist Finder повторно не вернёт. Уже отдано в рассылку: 0

Профили Dolphin

Отметь, с каких профилей писать. Артисты делятся между ними поровну, максимум 25 в день на профиль. Открытый профиль Money Hub сам перезапустит в режиме автоматизации.

Нажми «Загрузить из Dolphin».

Опенеры

Каждому артисту выбирается случайный шаблон. {Yo|Ayo} — случайное слово, {{first_name:bro}} — имя (или «bro», если имени нет), {{track}} — его трек, {{name}} — полное имя.

Расширение авторассылки

Сейчас работает с IG Sender Pro (режим «2026»): Money Hub находит его в профиле по названию, загружает туда артистов с опенерами и жмёт «Запустить». Расширение должно быть установлено и включено в профиле.

Как отправлять

Расширение выбирает способ для каждого артиста среди отмеченных. Профили Dolphin отмечаются в панели Dolphin Outreach (по 25 артистов на профиль в день).
