# Money Hub

Командный центр на Маке: одно окно, из которого запускаешь свой софт, видишь, что работает, и запускаешь **сценарии**, где несколько программ работают по цепочке.

## Этап 1 (главный экран)
Референс-артист и метрики → Artist Finder (его API на 127.0.0.1:8763) находит похожих → Dolphin Outreach: шаблоны опенеров и способы отправки (директ / сторис / пост) → импорт (опенер каждому) → рассылка по отмеченным профилям Dolphin. Тех, кому уже отдали в рассылку, Artist Finder повторно не вернёт.

## Что ещё умеет

**Программы**
| Программа | Что Money Hub делает |
|---|---|
| Dolphin Anty | открывает, показывает, запущен ли |
| Dolphin Outreach | включает сервер, показывает «отправлено сегодня / в очереди / профили», запускает и останавливает рассылку, переносит лиды, открывает панель |
| Type Beat Leads | открывает Chrome с YouTube, показывает последний экспорт лидов и перенесён ли он |
| Beat Visualizer | открывает приложение (или `index.html` в Chrome) |
| FL Tutorial Recorder | запускает и останавливает (при первом запуске сам ставит зависимости) |
| ManyChat | открывает кабинет |

**Сценарии**
- **Утренняя рассылка**: Dolphin Anty → Dolphin Outreach → свежий `type-beat-leads-*.csv` из «Загрузок» (только 🔥 горячие и тёплые) → рассылка по профилям, отмеченным в Dolphin Outreach.
- **Поиск лидов**: YouTube для Type Beat Leads + Spotify.
- **Контент-сессия**: FL Tutorial Recorder → Beat Visualizer.

Любой шаг можно выключить галочкой. Если шаг упал, следующие не выполняются, и видно почему.

## Установка
1. Скачай `.dmg` из релиза **money-hub-latest** (GitHub → Releases).
2. Перетащи Money Hub в «Программы». Первый раз: правый клик → «Открыть».
3. **Настройки** → «Папка с инструментами»: выбери папку с репозиторием `workspace-master`.

Нужен Node.js 22+ (он уже нужен для Dolphin Outreach).

## Разработка
```bash
cd money-hub
npm install
npm start      # запустить
npm test       # тесты сценария на поддельном Dolphin Outreach
npm run dist:mac
```
Программы и сценарии описаны в `core/modules.js`.
